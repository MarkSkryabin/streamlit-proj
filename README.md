Проект: Анализ погодных данных и аномалий (Streamlit)

**Функциональные возможности**

*Анализ исторических данных*

загрузка CSV-файла с историческими температурами

вычисление скользящего среднего (окно 30 дней)

расчёт средней температуры и стандартного отклонения по сезонам

выявление аномалий по правилу mean ± 2σ

просмотр таблицы аномалий

*Анализ текущей погоды*

получение текущей температуры по выбранному городу

сравнение текущей температуры с сезонной нормой

проверка, является ли текущая температура аномальной

*Визуализация*

временной ряд температур с выделением аномалий

сезонные профили температуры (среднее и стандартное отклонение)

интерактивные графики с помощью Plotly

Анализ производительности

сравнение синхронных (requests) и асинхронных (httpx) HTTP-запросов

эксперимент с несколькими запросами к API

сравнение последовательного и параллельного анализа данных

демонстрация случаев, когда асинхронность эффективна, а когда — нет



**Формат входных данных**

Исторические данные должны быть в формате CSV:

city,timestamp,temperature,season
New York,2010-01-01,0.34,winter
London,2010-01-01,4.12,winter

Где:
city — название города
timestamp — дата наблюдения
temperature — температура (°C)
season — сезон (winter, spring, summer, autumn)


**Установка и запуск**

Клонировать репозиторий

git clone https://github.com/Markos61/streamlit-proj/tree/main

cd your-repo-name

**Создать виртуальное окружение**

python -m venv .venv

**Установить зависимости**

pip install -r requirements.txt

**Запустить приложение**

streamlit run app.py

**API-ключ OpenWeatherMap**

Для получения текущей погоды необходим API-ключ:
https://openweathermap.org/api

Ключ вводится через интерфейс приложения и не хранится в коде.
